## Featured project

### [Casting Defect AI](https://github.com/dishantsawant24-bit/casting-defect-ai.)

A local-first casting inspection prototype using a 12-class ResNet18 classifier, an OpenCV input-screening heuristic, a Streamlit dashboard, and local SQLite inspection metadata.

**Technical areas:** Python, PyTorch, Torchvision, OpenCV, Streamlit, SQLite, GitHub Actions.

> The public repository currently contains the application source and tests. The trained checkpoint and sample data are kept out of Git until redistribution rights are confirmed. Model performance claims will be added only with a reproducible evaluation report.
