# Getting support

- **Bug reports:** use the Bug report issue form.
- **Feature ideas:** use the Feature request issue form.
- **Usage questions:** include your Python version, operating system, installation steps, and the full error message after removing secrets and private information.
- **Security concerns:** follow [SECURITY.md](SECURITY.md); do not post vulnerabilities publicly.

This is a community project maintained on a best-effort basis. There is no guaranteed response time or commercial support commitment.
